# pairwise-uvscroll

## 题面（可直接粘贴）

UV 滚动与多层视差。约束：滚动按速度累加取模；负速度正确；必须支持多层视差（每层速度系数）且帧索引与 UV 同步；循环接缝处 UV 与帧的跳变有上界（不得出现不连续）；层数或系数非法、非有限速度要报错；10 万次更新不超过 100 ms；无状态泄漏、并发安全。验收：cd uvscroll && python -m pytest tests -q -k scroll。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 并发安全
- 非有限输入分类报错
- 性能上界按题面

## 运行方式

```bash
python -m pytest tests -q
```
