# pairwise-tilefade

## 题面（可直接粘贴）

瓦片淡入淡出。约束：alpha 在 [0,1] 且随时间线性变化；结束精确到目标值；必须支持中途反向且不跳变（连续性上界）；非法时长报错；同帧多瓦片互不影响；10 万次更新不超过 100 ms。验收：cd tilefade && python -m pytest tests -q -k fade。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

- 并发安全
- 非有限输入分类报错
- 性能上界按题面
