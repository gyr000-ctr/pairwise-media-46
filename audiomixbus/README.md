# pairwise-audiomixbus

## 题面（可直接粘贴）

音频总线与发送。约束：总线求和后限幅；send 比例 0..1；必须实现侧链闪避（触发时总线增益按 attack/release 下降）且跨缓冲区状态连续；静音输入不影响总线；100 万样本不超过 300 ms；并发安全；非法比例报错。验收：cd audiomixbus && python -m pytest tests -q -k bus。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 并发安全
- 非有限输入分类报错
- 性能上界按题面

python -m pytest tests -q
