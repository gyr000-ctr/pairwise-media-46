# pairwise-colorblind

## 题面（可直接粘贴）

色盲模拟与可逆校正。约束：三类模拟矩阵行和为 1、白点与灰度不动；必须在感知均匀空间（OKLab）做模拟，不得只做线性矩阵；必须提供反向校正接口，模拟→校正往返误差 ≤0.02（比线性逆矩阵更低）；校正后色相偏移 ≤2°；输出钳制 [0,1]；10 万像素不超过 300 ms；并发安全；非法类型要给出可区分的错误。验收：cd colorblind && python -m pytest tests -q -k cvd。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 并发安全
- 非有限输入分类报错
- 性能上界按题面

## 运行方式

```bash
python -m pytest tests -q
```

初始 15 failed。可见测试只覆盖主功能（3 分线）。
